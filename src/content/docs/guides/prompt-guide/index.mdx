## Quick reference

### Agents

`01-Orchestrator` coordinates the end-to-end delivery pipeline and standalone WAF assessments (`resume <project>` continues any interrupted run). You can also select step owners (`02-Requirements`, `03-Architect`, `04-Design`, `04g-Governance`, `05-IaC Planner`, `06b-Bicep CodeGen`, `06t-Terraform CodeGen`, `07b-Bicep Deploy`, `07t-Terraform Deploy`, `08-As-Built`) or standalone specialists (`09-Diagnose`, `10-Challenger`, `11-Context Optimizer`) directly from the agent picker. See the [workflow roster](/concepts/workflow/#core-agents-by-workflow-step).

### Skills

Skills under `.github/skills/apex-*/SKILL.md` load domain procedures on demand into the active agent's context without changing permissions or bypassing gates. User-invocable skills include `/apex-workflow-start`, `/apex-github-operations`, and `/apex-debug-log-export`. Inspect the full inventory in the [Architecture Explorer](/reference/architecture-explorer/).

### Subagents

Step agents invoke stateless leaf subagents (`challenger-review-subagent`, `cost-estimate-subagent`, `bicep-validate-subagent`, `bicep-whatif-subagent`, `terraform-validate-subagent`, `terraform-plan-subagent`, and `policy-precheck-subagent`) for structured reviews, retail pricing, lint checks, previews, and policy prechecks. Leaf subagents are never selected directly in chat. See [skills and subagents](/reference/prompts/skills-subagents/#subagents).

### Prompt files

Legacy Local slash-adapter `.prompt.md` files were retired when APEX standardized on the VS Code **Copilot** session target; only `.github/prompts/waf-assess-existing.prompt.md` (`/waf-assess-existing`) remains active. Always select `01-Orchestrator` in the agent picker before running `/waf-assess-existing`.

#### Core workflow prompts

Open [workflow prompts](/reference/prompts/workflow-prompts/) for starter prompts covering `01-Orchestrator` delivery, `resume <project>`, `/waf-assess-existing`, and direct step-agent invocations.

#### Utility prompts

Routine repository operations use user-invocable skills rather than separate `.prompt.md` adapters: `/apex-workflow-start` for starting or resuming projects, `/apex-github-operations` for `gh` CLI-first commits, branches, and pull requests, and `/apex-debug-log-export` for [debug log export](/guides/apex-debug-log-export/).
